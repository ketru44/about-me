## 설계 설계 과정
`자기소개`라는 크고 명확한 주제가 정해진 이상 AI에게 전체를 맡기게 된다면 다소 획일화된 결과물이 나올 것 생각하여, 설계가 아닌 구현에서 AI에게 도움을 받는 방향으로 결정했습니다.

- 컨텐츠 정리
  - 개인정보, 취미, 프로젝트

- 디자인(UI) - 메모보드 컨셉
  - `아이디어 구상과 공부를 할 때 항상 손으로 직접 메모를 하는 습관이 있습니다. about-me를 구상하면서도 A4 용지에 끄적여 보고 있었는데, 이걸 있는 그대로 표현하면 진짜 제 모습을 표현할 수 있겠다는 생각이 들어 메모보드를 컨셉으로 잡았습니다.`
  - 상위 컨텐츠 파트
    - 각 파트는 하나의 포스트잇에 해당
    - 링크와 같은 컨텐츠는 손글씨 형태의 하이퍼텍스트로 구현
  - 컨텐츠 추가 설명
    - 포스트잇
      - 카테고리에 맞는 간단한 소개 작성
      - 개인정보, 취미, 프로젝트 별로 포스트잇
      - 추가로 입력 가능한 빈 포스트잇을 하나 두어 사용자가 입력 가능(저장은 X)
    - 손글씨
      - 클릭시 해당 링크로 이동
      - 깃헙 링크 등

## AI를 활용한 부분
- index.html 기본 구조 생성
- 지우개, 펜 css
- 포스트잇 위치가 흩어지도록 연출할 수 있도록 css 수정을 부탁
- 손글씨 느낌 나는 구글 폰트 탐색
- css 리팩토링

## 새로 알게 된 것
자기소개처럼 주제가 명확할 경우 AI를 활용하면 비슷비슷한 결과가 나오기 쉽다는 걸 느꼈다. 내 생각과 개성이 드러나도록 설계하는 과정이 중요하다고 생각했습니다.
그리고 그 내용을 AI가 이해할 수 있도록 전달하는 일은 역시나 어려웠습니다... (특히 css) 요구사항을 문서화하거나 전달하는 방식을 고민해야 할 것 같습니다.
