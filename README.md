## 설계 설계 과정
`자기소개`라는 크고 명확한 주제가 정해진 이상 AI에게 전체를 맡기게 된다면 다소 획일화된 결과물이 나올 것 생각하여 설계를 직접해보고 구현에서 AI에게 도움을 받는 방향으로 결정했습니다.

- 컨텐츠 정리
  - 개인정보, 취미, 프로젝트, 루틴, 취향

- 디자인(UI) - 메모보드 컨셉
  - `아이디어 구상과 공부를 할 때 항상 손으로 직접 메모를 하는 습관이 있습니다. about-me를 구상하면서도 A4 용지에 끄적여 보고 있었는데, 이걸 있는 그대로 표현하면 진짜 제 모습을 표현할 수 있겠다는 생각이 들어 메모보드를 컨셉으로 잡았습니다.`
  - 상위 컨텐츠 파트
    - 각 파트는 하나의 포스트잇에 해당
    - 링크와 같은 컨텐츠는 스티커 버튼으로 구현
  - 컨텐츠 추가 설명
    - 포스트잇
      - 카테고리에 맞는 간단한 소개 작성
      - 개인정보, 취미, 프로젝트, 취향, 루틴 별로 포스트잇
      - 추가로 입력 가능한 빈 포스트잇을 하나 두어 사용자가 입력 가능(저장은 X)
    - 스티커
      - 텍스트 스티커
      - 클릭시 해당 링크로 이동
      - 깃헙 링크 등
